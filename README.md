# DeFi Strategie Dashboard

Ein leichtgewichtiges Dashboard (HTML/CSS/JS), um Web3-Strategien wie Staking, Lending oder Funding-Rate Farming zu dokumentieren und auszuwerten.

## Features

- Strategien erfassen (Kategorie, Protokoll, Chain, Kapital, aktueller Wert, Notiz)
- Automatische Berechnung von Gewinn/Verlust und ROI
- Aggregierte Auswertung nach:
  - täglich
  - monatlich
  - jährlich
- Persistenz via `localStorage` im Browser
- Demo-Daten per Klick

## Start

Öffne `index.html` direkt im Browser oder starte lokal einen Webserver:

```bash
python3 -m http.server 4173
```

Dann im Browser: `http://localhost:4173`
